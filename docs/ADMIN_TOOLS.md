# Admin Tools

## ADMIN

- Sees ADMIN and CONSEILLER accounts only.
- Cannot see or manage LUCIFER accounts.
- Can create counselors, deactivate/reactivate counselors, delete counselors, force password change, and reset password.
- Can view assigned clients and requests per counselor.
- Can reassign clients and requests between counselors.

## LUCIFER

- Sees all accounts, including LUCIFER.
- Can create all roles.
- Can deactivate, delete, force password changes, and reset passwords for all visible accounts except self-deletion.
- Can review complete audit activity and system panel information.

## CONSEILLER

- Cannot access Administration.
- Cannot see ADMIN or LUCIFER user-management views.
