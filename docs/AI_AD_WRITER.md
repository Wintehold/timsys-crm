# AI Ad Writer

The Beta 1 ad writer is deterministic and does not call an external AI API.

For each Yakeey Vision Card, it generates:

- Avito: direct, conversion-oriented copy.
- Mubawab: structured premium real-estate copy.
- Marketplace: short human copy for quick contact.
- Instagram: social caption with restrained emoji and hashtags.

Each generated version contains a channel, title, body text, copy action, and regenerate action in the UI.
